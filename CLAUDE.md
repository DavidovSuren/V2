# Project Instructions

## Основное правило
Не читай весь проект целиком.

Для каждой задачи:
1. Сначала определи, какие файлы относятся к задаче.
2. Читай только эти файлы и необходимые зависимости.
3. Не перечитывай уже прочитанные файлы без необходимости.
4. Не открывай README.md, если информация из него не нужна для текущей задачи.
5. Не сканируй весь проект для обычной задачи.

## Не трогать и не читать без необходимости

- .git/
- node_modules/
- dist/
- build/
- coverage/
- .cache/
- tmp/
- logs/

## Проект

Backend: Go 1.22

Основная структура:
- cmd/ — точки запуска
- internal/ — внутренняя логика
- data/ — данные
- templates/ — HTML-шаблоны

## Работа с кодом

- Делай минимальные изменения.
- Не переписывай рабочий код без необходимости.
- Перед большой переработкой сначала объясни план.
- После изменения запускай подходящие тесты или проверки.

## Context rules

- Не исследуй весь проект, если задача касается конкретной части.
- Сначала используй поиск по именам файлов, функциям и символам.
- Читай только релевантные файлы.
- Не перечитывай файл, если он уже был прочитан и не изменился.
- Не используй subagents для простой задачи или изменения одного файла.
- Не запускай широкое исследование проекта без необходимости.
- Не читай README.md без необходимости.
