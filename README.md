# Версия 2.0 — Telegram Mini App

Персональная игра по созданию улучшенной версии себя за 365 дней.  
Одно действие в день. Прогресс. STREAK. XP. Достижения.

---

## Описание

**Версия 2.0** — это Telegram Mini App, в котором пользователь:

1. Проходит короткую анкету и загружает фото.
2. Получает персональный профиль «Version 2.0».
3. Каждый день выполняет **одно** конкретное действие.
4. Отмечает состояние в дневнике.
5. Следит за прогрессом по 8 направлениям жизни.
6. Копит XP, уровни и STREAK.

Главный принцип продукта: не список из 20 задач, а **одно действие в день**.

## MVP-функциональность

| Экран | Что реализовано |
|-------|-----------------|
| **Приветствие** | Имя, возрастная группа, загрузка 3 фото |
| **Анкета** | 20 вопросов по 8 направлениям (single / multi / scale / text) |
| **Главная** | Круговой прогресс, дни до цели, сегодняшнее действие, кнопки «Выполнил / Пропустить / Почему» |
| **Прогресс** | 8 категорий + XP, уровень, STREAK, выполненные задания |
| **Дневник** | Эмодзи-состояние + текстовая заметка |
| **Достижения** | 8 бейджей (unlocked / locked) |
| **Профиль** | Подписка 369 ₽/мес, статистика, выход |
| **Отчёт** | Недельный отчёт + кнопка «Поделиться» |

Дополнительно:
- Поддержка светлой / тёмной темы Telegram
- Нижняя навигация
- Модальные окна
- Тосты (+XP)
- Локальное сохранение (localStorage)
- Адаптив под мобильные экраны

## 8 направлений развития

1. **Внешность** — образ, уход, фотографии  
2. **Стиль** — одежда, аксессуары, визуальный образ  
3. **Тело** — движение, активность, сон  
4. **Деньги** — финансовая дисциплина и планирование  
5. **Отношения** — коммуникация, границы, близкие  
6. **Окружение** — люди и пространство  
7. **Карьера** — навыки и рабочие цели  
8. **Образ жизни** — порядок, хобби, свободное время

## Как запустить

### 1. Локально в браузере

Просто откройте `index.html` в любом современном браузере.

### 2. В Telegram Mini App

1. Создайте бота через [@BotFather](https://t.me/BotFather).
2. Загрузите `index.html` на любой хостинг (GitHub Pages, Vercel, Netlify, свой сервер).
3. В BotFather:
   ```
   /setmenubutton
   → выберите бота
   → укажите URL вашего index.html
   → название кнопки: «Открыть Version 2.0»
   ```
4. Также можно использовать:
   ```
   /newapp
   ```

### 3. Тестирование темы

В Telegram Desktop / Mobile приложение автоматически подхватит светлую или тёмную тему пользователя.

## Состояния и механики

- **Выполнил** → открывается дневник → после сохранения начисляется XP и обновляется прогресс
- **Пропустить** → модальное подтверждение → действие считается пропущенным до следующего дня
- **Почему я это делаю?** → модалка с пояснением
- Прогресс и STREAK сохраняются локально (в реальном продукте будут на бэкенде)

## Что сознательно оставлено как заглушки (MVP)

Согласно ТЗ, следующие функции вынесены во вторую очередь:

- AI-генерация визуальной карточки «Ты через 365 дней»
- Фото-эволюция (Day 0 → Day 30 → Day 90 → Day 180 → Day 365)
- Реальная оплата подписки
- Генерация персональных заданий через AI
- Ежемесячный отчёт как отдельный экран
- Полноценный шаринг карточки в Telegram

В текущей версии на их месте стоят понятные заглушки.

## Интеграция с бэкендом (будущее)

Сейчас все данные — моки + `localStorage`.  
Структура уже готова к подключению API:

```js
// Пример будущего запроса
fetch('/api/daily-action', {
  method: 'GET',
  headers: {
    'Authorization': `tma ${Telegram.WebApp.initData}`
  }
})
```

Рекомендуемый стек бэкенда:
- Node.js / Python (FastAPI)
- PostgreSQL
- AI API (для генерации заданий и анализа анкеты)
- Telegram Bot API (уведомления)
